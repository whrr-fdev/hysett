# HySett

Единая графическая оболочка и центр управления для композитора Hyprland (C++20, Qt6 Quick/QML, LayerShellQt, GLSL 440). Заменяет waybar, mako и rofi.

## Возможности

- Панель задач: 4 позиции на экране, режим островка или во всю ширину, Drag-and-Drop редактор модулей, рабочие столы, погода, плеер MPRIS2 с эквалайзером, индикаторы загрузки треков, проверки VPN, записи экрана, таймера и секундомера, системный монитор, SNI-трей, выпадающие микшеры звука и Bluetooth, сеть, раскладка и питание.
- Музыка и Яндекс.Музыка: встроенный плеер по локальным плейлистам с обложками, синхронизация пользовательских плейлистов и «Моей волны» (`~/Music/YandexMusic`), фоновая автодокачка новых треков при появлении интернета.
- Шейдерная графика: плавное слияние краев выпадающих окон с панелью задач (merged_shell.frag), жидкие ферромагнитные волны музыки, эффекты преломления (liquid_glass.frag), переходы между вкладками и процедурное небо погоды.
- Динамическая тема: извлечение цветовой палитры из текущих обоев (awww / mpvpaper) и синхронизация цветов с Hyprland, Kitty, Firefox, GTK3/GTK4, Btop и AyuGram.
- Встроенный VPN (sing-box): системный TUN-туннель singbox_tun0, раздельное туннелирование для РФ (RU Direct), поддержка подписок и обхода белых и чёрных списков.
- Уведомления и утилиты: DBus-демон org.freedesktop.Notifications с историей на 50 записей, поиск файлов, монитор процессов, время (часы, календарь, таймер, секундомер), буфер обмена (cliphist), галерея обоев и настройки Hyprland.

## Флаги запуска

| Команда | Описание |
| :--- | :--- |
| hysett --daemon | Фоновый режим (панель задач, уведомления, IPC-сокет) |
| hysett | Открыть или закрыть центр управления |
| hysett --wallpaper | Полноэкранный выбор обоев |
| hysett --apps | Лаунчер приложений |
| hysett --search | Глобальный поиск файлов |
| hysett --clipboard | История буфера обмена |
| hysett --power | Меню питания |
| hysett --atmosphere-overlay | Погодный оверлей рабочего стола |

## Сборка и запуск

    cd ~/hysett
    cmake -B build -S .
    cmake --build build -j$(nproc)
    pkill -x hysett || true
    ./build/hysett --daemon &
