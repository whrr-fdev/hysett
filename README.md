# 󰣇 HySett — Hyprland Control Center

**HySett** — единый графический центр управления, лаунчер приложений, менеджер обоев и глобальный поиск для среды **Hyprland** (C++20 + Qt6 Quick / QML + кастомные GLSL-шейдеры). Работает в режиме мгновенного фонового демона с динамической выгрузкой неактивных страниц и GPU-ресурсов из ОЗУ.

---

## ✨ Основные возможности

- **Настоящие GLSL-шейдеры и Liquid Glass**:
  - **Жидкое стекло (`liquid_panel.frag`, `liquid_glass.frag`)** — объемные 3D-мениски по краям карточек, оптическое преломление и блики без потери прозрачности.
  - **Гидродинамический след курсора и волны клика (`cursor_fx.frag`, `click_fx.frag`)** — локальные 160-FPS шейдеры: курсор оставляет след рассекаемой воды при движении, а при клике расходится настраиваемая волна или световая вспышка (*Кольцо / Импульс / Звезда / Двойная волна*).
  - **Динамическая подсветка границ окна (`neon_border.frag`)** — бегущие световые волны строго по контуру окна и диалоговых окон с выбором направления (*По часовой / Против часовой / Навстречу*), палитры и реакции на близость курсора.
  - **Шейдерные переходы между вкладками (`vortex_suck.frag`)** — *«Воронка»* (спиральное засасывание в центр), *«Портал»* (3D сферическая линза с энергетическим кольцом), *«Телепорт»* (квантовый распад на полосы с хроматической дисперсией), а также классические *Слайд / Глубина / Пружина*.
- **Кастомизация цветов и палитры (`ColorPickerModal.qml`)**:
  - Встроенная интерактивная 2D HSV-палитра с полосой оттенка (Hue), пресетами и `#HEX`-вводом.
  - Поддержка как единого акцентного цвета, так и раздельного редактирования: *Акцент интерфейса*, *Свечение границ*, *Курсор и вспышка*, *Фон окна*, *Фон карточек*.
- **Двуязычный интерфейс (`RU` / `EN`)**:
  - Мгновенное переключение между **Русским** и **English** на лету без перезапуска приложения.
- **Адаптивный полноэкранный режим обоев**:
  - В обычном окне — 3 вертикальные колонки (*Настройки / Категории / Лента превью*).
  - При разворачивании на весь экран (`SUPER + F` или запуск с `--wallpaper`) — элементы плавно перелетают: настройки смещаются влево-вниз, обои и категории выстраиваются в компактные горизонтальные полосы внизу, а прозрачность и блюр окна плавно уходят в `0%`, открывая ~80% экрана для просмотра рабочего стола.
- **Глобальный поиск и поиск по настройкам**:
  - На экране приветствия — живой фильтр по всем параметрам центра управления (подходящие карточки плавно поднимаются наверх и выстраиваются в одну колонку).
  - Вкладка **«Поиск»** — асинхронный поиск по всем файлам системы (`fd` / `find`, домашняя папка `~` или вся система `/`) и установленным приложениям `.desktop`.

## 🚀 Флаги запуска и горячие клавиши

| Команда / Флаг | Описание | Хоткей в `hyprland.lua` / Waybar |
| :--- | :--- | :--- |
| `hysett --daemon` | Запуск фонового IPC-демона (в автозапуске, окно скрыто, ОЗУ очищено) | Автозапуск при старте Hyprland |
| `hysett` | Открыть / скрыть главное окно центра управления | `SUPER + Escape` |
| `hysett --wallpaper` | Открыть сразу вкладку **«Обои»** в полноэкранном режиме (`0%` блюра/фона) | `SUPER + W` |
| `hysett --apps` | Открыть окно в плавающем режиме сразу на вкладке **«Приложения»** | `SUPER + D` |
| `hysett --search` | Открыть окно сразу на вкладке **«Поиск»** (файлы и программы) | Клик по логотипу `󰣇` (Arch) на Waybar |

## 📁 Архитектура и сводка по файлам проекта

| Путь к файлу | Роль в проекте |
| :--- | :--- |
| `CMakeLists.txt` | Сборка C++20 + Qt6 (`Quick`, `QuickControls2`, `ShaderTools`, `Concurrent`), компиляция `.frag` шейдеров в `.qsb`. |
| `install.sh` | Автоматический установщик пакетов, конфигов из `dotfiles/`, сборщик проекта и генератор `.desktop` файла. |
| `dotfiles/` | Полная копия пользовательских конфигов (`hypr/`, `waybar/`, `mako/`), скриптов виджетов и шейдеров экрана. |
| `src/main.cpp` | Точка входа: настройка аллокатора `glibc`, парсинг CLI-флагов (`--daemon`, `--wallpaper`, `--apps`, `--search`), регистрация синглтонов. |
| `src/AppInstance.{h,cpp}` | Single-instance локальный IPC-сервер: мгновенное открытие/скрытие окна по повторному вызову бинда. |
| `src/AppConfig.{h,cpp}` | Конфигурация `control_center.conf`: масштаб, высота окна, цвета, параметры подсветки и курсора, видимость вкладок, словарь переводов RU/EN. |
| `src/ThemeEngine.{h,cpp}` | Движок темы: скругления (`theme_toggle.sh`), плавная кривая блюра окна Hyprland с сериализацией без гонки процессов, параметры Liquid Glass. |
| `src/HyprIpc.{h,cpp}` | Взаимодействие с Hyprland IPC и глубокая фоновая очистка памяти (`performDeepMemoryTrim`, `releaseResources`, `malloc_trim`). |
| `src/LookManager.{h,cpp}` | Вкладка «Окна»: прозрачность, зазоры, рамки, блюр, тени, стек отката `↩ Откатить (N)`, генерация `look.lua`. |
| `src/AnimsManager.{h,cpp}` | Вкладка «Анимации»: скорости и кривые Безье для окон, слоев и рабочих столов Hyprland. |
| `src/CursorManager.{h,cpp}` | Вкладка «Курсор»: тема, размер курсора и настройки экранной лупы. |
| `src/MonitorsManager.{h,cpp}` | Вкладка «Мониторы»: разрешение, герцовка, масштаб, ориентация, VRR, DPMS и 10-секундный таймер подтверждения. |
| `src/DevicesManager.{h,cpp}` | Вкладка «Устройства»: раскладки клавиатуры, хоткей смены языка, повтор клавиш, сенса мыши и тачпад. |
| `src/NetworkManager.{h,cpp}` | Вкладка «Сеть»: сканирование и подключение к сетям Wi-Fi через `nmcli`. |
| `src/BluetoothManager.{h,cpp}` | Вкладка «Блютуз»: управление питанием адаптера, поиск и сопряжение устройств. |
| `src/WaybarManager.{h,cpp}` | Вкладка «Waybar»: позиция панели, отступы, прозрачность пилюль, генерация CSS. |
| `src/MakoManager.{h,cpp}` | Вкладка «Mako»: геометрия, таймауты, шрифт, прозрачность и цвета рамок (включая `[urgency=critical]`), тест уведомлений. |
| `src/AutostartManager.{h,cpp}` | Вкладка «Автозапуск»: управление службами и командами при старте Hyprland. |
| `src/BindsManager.{h,cpp}` | Вкладка «Бинды»: просмотр и редактирование горячих клавиш Hyprland. |
| `src/RulesManager.{h,cpp}` | Вкладка «Правила окон»: управление правилами плавающих окон, размеров и привязок. |
| `src/AppsManager.{h,cpp}` | Вкладки «Приложения» и «Поиск»: парсинг `.desktop` файлов и асинхронный поиск файлов по системе (`fd` / `find`). |
| `src/WidgetsManager.{h,cpp}` | Вкладка «Виджеты»: управление оверлеем клавиатуры/мыши (`kb_overlay`), часами на рабочем столе и системными мониторами (`btop`, `fastfetch`, `peaclock`). |

| `qml/components/*` | Библиотека кастомных компонентов: `Sidebar`, `NavButton`, `GlassPanel`, `StyledSlider`, `StyledSwitch`, `StyledButton`, `StyledComboBox`, `StyledCheckBox`, `SegmentedButton`, `ColorPickerModal`. |
| `qml/views/*` | Все 19 экранов центра управления (`WelcomeView`, `SearchView`, `LookSettingsView`, `WallpapersView`, `MakoSettingsView`, `AppSettingsView` и др.). |
| `qml/shaders/*.frag` | GLSL-шейдеры (`liquid_panel.frag`, `liquid_glass.frag`, `neon_border.frag`, `cursor_fx.frag`, `click_fx.frag`, `dialog_blur.frag`, `vortex_suck.frag`). |

## 🛠 Установка и сборка на новой системе

Для полной автоматической установки всех зависимостей, конфигов, виджетов и сборки проекта достаточно выполнить:

```bash
git clone <путь_или_репозиторий> ~/hysett
cd ~/hysett
./install.sh
```

Для ручной пересборки без перезаписи конфигов:

```bash
cd ~/hysett
cmake -B build -S .
cmake --build build -j$(nproc)
pkill -x hysett || true
./build/hysett --daemon &
```
